7 LEGUAS FEED & SEEDS — CLEAN GITHUB PAGES UPLOAD

1. Create a NEW public GitHub repository, for example 7-leguas-feed-and-seeds.
2. Extract this ZIP on your computer. Upload the CONTENTS of the ZIP to the root of the new repository, then commit. Do not upload the ZIP itself or put the files inside another folder.
3. The repository top level must show index.html, CNAME, assets/, and es/.
4. Repository Settings > Pages > Build and deployment: Deploy from a branch; main; /(root); Save.
5. Under Settings > Pages > Custom domain, enter feeds7leguas.anchorglobaltech.com and Save.
6. In Fastmail > Settings > Domains > anchorglobaltech.com > Customize DNS, set one CNAME: Host feeds7leguas; Target anchorglobaltech956.github.io. If the same host has an old record, replace that record. Do not change Fastmail email records.
7. Wait for GitHub Pages to publish; use its Visit site button. Check that the English and Spanish photos load on a phone before sharing. Turn on Enforce HTTPS when GitHub makes it available.
